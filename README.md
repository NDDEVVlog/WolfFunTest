---

## Controls

This project features a fully implemented cross-platform input system, supporting both PC peripherals and Mobile touch interfaces.

### PC (Keyboard & Mouse)
* **Movement:** `W` `A` `S` `D`
* **Normal Attack:** `Right-Click`
* **Skill 1:** `Q`
* **Skill 2:** `R`

### Mobile (Touch)
* **On-Screen Controls:** Use the UI buttons provided in the Scene Overlay. The interface automatically maps touch inputs to movement, basic attacks, and character skills.
